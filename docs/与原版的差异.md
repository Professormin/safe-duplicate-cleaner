# 对照 check_dups2.py 的改动说明

本次以用户提供的 check_dups2.py 实际代码为依据。原文件只读对照，没有改写或执行。

## 已恢复的使用习惯

| 原版好用的地方 | 当前版本 |
| --- | --- |
| 放进目标文件夹，双击运行 | 保留，无参数时扫描脚本所在目录 |
| 顶部 MOVE_DUPLICATES 开关 | 保留；交付默认 False |
| EXTENSIONS 文件类型筛选 | 恢复，扩展名大小写不敏感 |
| 先统计大小，仅同大小候选计算哈希 | 恢复，不读取大小唯一文件的内容 |
| 分阶段显示扫描、比对、处理、报告 | 恢复四阶段，另有每秒状态心跳 |
| 显示发现重复和成功隔离 | 恢复，显示名称和容量 |
| 扫描、重复、隔离数量与容量及耗时 | 保留，并区分完整目录与零散文件 |
| Excel 可打开的 UTF-8 BOM CSV | 恢复；另保留 JSON 明细和中断日志 |
| 报告和隔离区放在目标目录内 | 保留，自动排除根目录下这两个专用目录 |
| 结束后按回车退出 | 保留，无参数运行时发生异常也会停留 |

## 为满足文件夹完整性要求保留的变化

- 先按结构与内容处理同级完整重复文件夹，再处理未受保护的叶子目录内部散文件。跨目录散文件仅报告，不按旧版全局逐文件隔离。
- 执行前重新枚举源与保留目录，检测新增、缺失和改变；不能只复核旧清单里的文件。
- 用同文件系统重命名隔离，不通过 shutil.move 跨盘复制后删除。
- 每个项目先记录 pending，完成后记录 done；异常保留运行锁，防止未经核查继续运行。
- 隔离位置增加运行编号和项目编号。原路径和目标位置均写入 CSV 与日志，避免历史同名冲突。
- 大小唯一或被类型筛选排除的文件不计算哈希，但仍记录在目录结构中。含未验证成员的文件夹不作为完整重复处理，避免连带隔离未选择的文件类型。

## 仍与原版不同的边界

- 提供的原版 MOVE_DUPLICATES=True，交付版默认 False；可以继续通过同名配置开关开启隔离。
- 原版跳过零字节文件；当前版本允许零字节内容判重，并有测试覆盖。
- 原版有些读取错误会计数并继续；当前扫描遇到访问失败、链接或特殊文件保守停止，避免不完整清单参与完整目录判重。执行复核失败则跳过对应项。
- 类型筛选不改变完整目录清单，因此扫描总数与容量包括未选类型；候选哈希与隔离仅针对选中类型。
- 最终成功隔离统计以已写入完成记录的项目为准；在重命名与完成记录之间退出的项目，需要通过 pending 日志核查。

## 本轮验证

32 项模拟测试通过。本轮新增检查：大小唯一的文件确实未调用内容读取；未哈希成员不会误判为完整目录重复；类型筛选不会连带隔离未选文件；CSV 路径、容量、状态及 Excel 所需编码正确。未扫描或清理真实资料。
