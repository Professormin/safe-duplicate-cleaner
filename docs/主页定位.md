# 主页定位与发布文案

## 一句话定位

给硬盘越买越多、资料越找越难、又不敢误删的人，一个从重复副本开始的保守整理工具。

## 核心痛点

用户用反复复制缓解丢失焦虑，却因此积累更多无法辨认的副本。整理需要连续时间和反复判断，因此一直推迟；找资料的成本又持续上升。

对模拟工作者而言，模型、输入、配置、结果等资料之间存在关系。是否保住完整项目，比“清掉多少 GB”更能建立信任。当前工具以目录结构和字节内容判重，不理解项目关系的业务含义，不能宣传为验证模拟工程有效性的工具。

## GitHub About 描述

盘越来越多，资料却越来越难找。面向怕误删、没时间整理数字资产的人：先处理完整重复文件夹，再处理零散重复文件；默认预览，隔离不删除。

## 推荐 Topics

`python` `duplicate-files` `file-management` `data-organization` `digital-assets` `cli` `windows`

待真正实现可安装 skill 后，再加入相应标签。

## 主页阅读顺序

1. 深色横幅与一句话痛点，让读者快速判断是否与自己有关。
2. 熟悉的目录名字、痛点表格和真实创作动机，建立共鸣。
3. 目录前后对比说明整套保留，避免先堆算法术语。
4. 只预览的入门命令，再给出测试证据和边界。
5. 跨盘检索、离线目录、AI skill 标记为尚未实现的探索方向。
6. 用具体问题邀请反馈：找不到什么、怕误删什么、为什么没整理。

## 宣传边界

不承诺零风险，不编造用户数量、下载量、性能或节省空间数据，不把异盘备份描述成应删除的垃圾。不将跨盘搜索、自动恢复、图形界面或 skill 宣传为现有功能。
