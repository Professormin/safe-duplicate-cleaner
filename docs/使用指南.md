# Safe Duplicate Cleaner · 两级重复文件安全清理

保守的 Python 重复文件整理工具：**先处理完整重复文件夹，再处理零散重复文件，优先保持文件夹完整。** 默认仅预览，实际操作也只隔离，不删除数据。

## 环境

- Python 3.10 或更新版本，无需安装第三方库。
- 已在 Windows 模拟目录中验证。其他系统尚未实机验证。

## 使用

下载仓库 ZIP 并解压，或克隆仓库。在程序所在目录打开终端。

先预览，扫描路径与报告路径必须分开：

```powershell
python "两级重复文件安全清理.py" "D:\待整理资料" --output "D:\清理报告"
```

检查生成的 JSON 报告后，如需实际隔离，显式添加 `--apply`：

```powershell
python "两级重复文件安全清理.py" "D:\待整理资料" --output "D:\清理报告" --apply
```

隔离项位于扫描根目录中的 `_重复文件隔离区/运行编号/项目编号/原名称`。日志记录原位置、保留副本位置和隔离位置。隔离仍占用磁盘空间，本工具不提供永久删除命令。

## 判重与保护规则

1. 完整文件夹只在同一父目录下比较；相对文件路径、大小、SHA-256 和空目录结构必须一致。
2. 外层完整重复优先。按名称顺序保留一份，其他完整副本整目录隔离；整个重复组不再参加二级清理。
3. 零散文件仅在未受保护的叶子目录内部判重。包含子目录的父目录不清理零散文件。
4. 跨目录零散重复只报告，不移动。部分复制的目录不会被合并或拆散。
5. 执行前重新核查两侧内容和目录结构；发现变化或不可读即跳过。扫描遇到不可读项、链接或特殊文件会停止。

本工具有意少清理一些重复数据，以避免破坏资料组织结构。

## 中断与恢复核查

每次隔离先写入并同步 pending 日志，重命名成功后再写 done。采用同文件系统重命名，不回退到复制后删除。

异常中断会保留 `_重复文件隔离区/运行锁`，阻止盲目重跑。锁目录中的 `日志路径.txt` 指向日志，可以只读核查：

```powershell
python "两级重复文件安全清理.py" --audit "D:\清理报告\清理日志_运行编号.jsonl"
```

`--audit` 只报告源和目标是否存在，不代表完成内容校验或恢复。请核对未完成项目及隔离内容；需要恢复时，先确认原路径未被占用。工具不自动覆盖恢复，也不自动解除异常运行锁。人工确认完成后再解除锁并重新预览。

## 安全边界

- 实际操作前保留独立备份，并停止同步、下载、复制等写入扫描目录的程序。最后复核与重命名之间仍有并发修改窗口，运行锁不能阻止其他应用写文件。
- 比较普通文件的主数据流，不比较 Windows ADS、ACL 等扩展元数据。
- 相同内容不等于文件有效；两份内容相同的损坏文件也可能被判重。
- 不保证恶意并发替换、硬件故障、断电或网络文件系统异常时的事务安全。
- 完整哈希偏重安全，大目录会有较高的读取和内存开销。
